# External skill intake

Use this procedure for a requested upstream import/update or an explicit `skills.sh`, `npx skills` or `bunx skills` operation. The generic CLI is an intake tool; this repository's guarded installers own deployment.

Resolve the actual upstream repository, exact commit, source files and license. Inspect downloaded instructions/helpers before execution. Stage imports outside active discovery; record file hashes and inherited notices. Compare existing personal, optional, local, system and plugin owners before adding an entrypoint. Preserve useful distinct procedures as conditional references when an owner already exists.

Keep client-specific frontmatter, invocation behavior and tool dependencies explicit. Do not silently replace a plugin package or execute another runtime's agents through a similarly named Codex tool. Treat missing licenses as unresolved redistribution permission. Public publication remains a separate decision.

Use the canonical validation, qualification and deployment workflow in SKILL.md. An external CLI's installed receipt does not establish our deployment state, provider connectivity or behavioral qualification. Original skills-cli resources remain preserved in library/skills/skills-cli as archival source; consult them as data for an explicit CLI task, not an alternate default installer.
