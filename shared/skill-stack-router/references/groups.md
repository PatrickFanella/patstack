# Task stacks

Use the current default owner first. For a specialist, choose the relevant
task set below and ask the read-only lookup for its members. Read one
needed procedure at a time; selecting a set is not required for lookup.

| Stack | Task |
|---|---|
| `core` | Everyday repository work, debugging, delivery, web/API changes, tools, documentation and basic operations. |
| `build-agent-tools` | Build and configure agents, MCP servers, CLIs, retrieval, evaluations and development environments. |
| `build-and-ship` | Take a feature from understanding and design through implementation, review, tests and a PR. |
| `creative-production` | Plan and produce visual, audio, video or slide material with a coherent voice and delivery format. |
| `data-and-decisions` | Investigate evidence, analyze data, compare alternatives and communicate a decision. |
| `diagnose-and-repair` | Reproduce a failure, inspect code/runtime evidence, repair it and prove the result. |
| `fiction-and-worlds` | Develop stories and settings, draft scenes, revise character/dialogue, and maintain continuity. |
| `learn-and-practice` | Plan learning, study examples, tutor, build exercises and review progress. |
| `mobile-and-interfaces` | Build and test mobile, terminal, editor, browser and interactive interfaces. |
| `operate-homelab` | Operate services and personal tools, investigate incidents, change infrastructure and verify recovery. |
| `product-and-launch` | Research a market, choose positioning, prepare brand/product copy, refine the interface and plan a launch. |
| `research-and-write` | Find and check sources, develop an argument, write or revise, and produce documents. |
