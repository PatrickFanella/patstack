# Specialist groups

Choose one relevant group, then use the read-only lookup to inspect its members.
Keep available default/system/plugin owners first. Full group membership and the
human guide are maintained in patstack `profiles/CATALOG.md` and `docs/SKILL-GROUPS.md`.

| Group | Task area |
|---|---|
| `core` | Always active. |
| `ai-agents` | Agent orchestration, client configuration and skill authoring. |
| `engineering` | Planning, understanding and delivering code changes. |
| `testing-quality` | Review, verification and test work. |
| `backend-devops` | Service code, payments, workflows and infrastructure. |
| `security` | Security review, forensics and hardening. |
| `frontend-mobile` | Web, mobile, terminal and editor interfaces. |
| `tooling-homelab` | Personal tools, homelab services and client setup. |
| `docs-research` | Office documents, research and reports. |
| `learning` | Courses, tutoring and practice. |
| `product-growth` | Product strategy, marketing and sales. |
| `creative-media-design` | Images, video, sound, slides and game design. |
| `writing-nonfiction` | Articles, essays, talks and voice. |
| `writing-worldbuilding` | Fiction craft, worldbuilding and tabletop play. |

Read only the selected specialist and its applicable references. The categories
organize discovery; they do not grant authorization or runtime capabilities.
