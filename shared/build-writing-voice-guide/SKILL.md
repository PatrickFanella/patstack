# build-writing-voice-guide

Distinguish a person's writing patterns from product voice rules. Record evidence and uncertainty; do not invent a brand personality or author experience.

Select the matching procedure below and load only that procedure and its needed resources. Each procedure retains its own client, tool and invocation limits. Internal handoffs use the matching procedure below rather than reloading this entrypoint. A reference does not authorize delegation, publication, deployment or an unrelated mutation.

- **voice ledger**: Use when defining or reviewing a product's written voice guide from brand sources and real copy samples. Read [the procedure](references/base-workflow.md).
- **voice fingerprint**: Writer voice analysis: extract a writer's style patterns into a voice guide so new text can match it. Use when capturing a voice or writing in someone's established style. Read [the procedure](references/modes/voice-fingerprint/guide.md).
