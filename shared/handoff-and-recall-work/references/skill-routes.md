# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `investigate-code` | optional | When recalling work on a named feature, file or subsystem needs the shared record searched. |
| `write-plainly` | required | When writing a recall brief for the user. |
| `improve-workflow-from-sessions` | optional | When recalled work shows a habit worth turning into a durable skill. |
