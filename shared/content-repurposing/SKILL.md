# Content repurposing

Use when there is an actual source asset to adapt into other formats. If the user needs a product's facts and positioning established first, create that context before treating it as approved material. A single rewrite does not require a distribution plan.

Read the source, product voice, and requested channels. Identify the source revision, date, rights, and claims worth carrying forward. A supplied transcript may need checking against its recording before quotation.

1. Extract useful units: a demonstrated task, supported fact, attributed quotation, example, or explanation. Keep exact evidence pointers. Do not make up a quote, metric, or user story to complete a format.
2. Match each unit to a requested channel and reader. Choose a few useful derivatives rather than filling every possible platform.
3. Draft each piece for its format: one idea, an appropriate opening, a supported next action, and a checked destination. Preserve qualifications that affect the reader's decision.
4. Reference the product's existing artwork/layouts for visual derivatives. Distinguish a real product capture from a storyboard. Record attribution, footage/audio permissions, captions, and final alt text where relevant.
5. If requested, suggest a manageable release sequence with owner and review date. Drafting a sequence does not submit a schedule or publish content.

Return a source-to-derivative map and the actual drafts. For each draft record channel, purpose, source passage or claim ID, destination, and any missing evidence or rights. Check current format limits when exact compliance matters; say which checks were actually run.
