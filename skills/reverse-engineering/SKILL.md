# reverse-engineering

Identify the artifact and authorized analysis scope. Select binary inspection or protocol observation; report inferred structure separately from demonstrated behavior.

## Select a mode

- Master binary analysis patterns including disassembly, decompilation, control flow analysis, and code pattern recognition. Read [the procedure](references/modes/binary-analysis-patterns/guide.md).
- Master network protocol reverse engineering including packet analysis, protocol dissection, and custom protocol documentation. Read [the procedure](references/modes/protocol-reverse-engineering/guide.md).

Resource paths inside a mode are relative to that mode directory. Run its scripts from that directory or use absolute script paths, passing the target repository explicitly.
