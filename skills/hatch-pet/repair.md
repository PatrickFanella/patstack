# Repair an existing pet

Inspect the existing atlas, request, manifests, and QA findings before modifying it. Preserve successful rows and raw source images. Read [the repair workflow](repair-workflow.md) for an ordinary failing row. A look-direction failure requires [the look-direction procedure](required-v2-look-direction-stage.md): regenerate its coherent row, never patch an individual final look cell.

Run relevant existing geometry and image checks before generating anything. A request to inspect or validate a pet does not authorize regeneration. Close the [acceptance criteria](acceptance-criteria.md) and apply [the validation rules](rules.md) before packaging a requested repair.
