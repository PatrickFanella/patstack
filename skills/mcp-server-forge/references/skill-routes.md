# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `behavior-proof` | required | Before claiming the server/tool contract works. |
| `mcp-wire-tracer` | optional | When client registration, initialization or tool discovery needs diagnosis. |
| `go-craft` | optional | When implementing the server in Go. |
| `ts-type-design` | optional | When implementing a TypeScript server contract. |
