# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `typescript` | optional | When a major upgrade produces type errors or requires tsconfig changes. |
| `python-projects` | optional | When the task turns out to be a routine uv dependency update. |
| `investigate-code` | optional | When a breaking change is undocumented and the pinned dependency source must be read. |
| `verify-implementation` | optional | Before claiming the upgraded dependency is compatible. |
