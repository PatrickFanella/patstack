# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `coordinate-parallel-agents` | optional | When interface or sketch alternatives are explicitly requested as parallel candidates. |
| `define-requirements` | optional | When a design choice depends on an unresolved product requirement. |
| `plan-and-implement-changes` | optional | When the chosen design should proceed to an implementation plan. |
| `refactor-code` | optional | When an agreed module deepening is to be carried out without changing behavior. |
