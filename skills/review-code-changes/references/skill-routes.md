# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `write-and-revise-nonfiction` | optional | When changed documentation may disagree with implementation. |
| `secure-web-code` | optional | When the user asks for a security review of code beyond the diff. |
| `react-and-nextjs` | optional | When a React or Next.js diff carries rendering or bundle risk. |
| `build-and-fix-ci` | optional | When the reviewed PR's hosted checks are failing. |
| `investigate-code` | optional | When a finding depends on why the existing code is shaped that way. |
