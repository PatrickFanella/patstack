# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `temporal-workflows` | optional | When verifying Python Temporal replay, timers or determinism. |
| `control-browser-and-desktop` | optional | When the client permits terminal browser QA and no more specific browser contract takes precedence. |
| `map-codebase` | optional | When repository structure is unknown. |
| `manage-git-and-prs` | optional | Only when the user asks to ship changes after the read-only readiness assessment. |
| `fix-bugs` | optional | When the user asks for a FAIL result to be diagnosed or fixed. |
