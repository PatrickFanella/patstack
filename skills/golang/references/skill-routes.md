# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `build-mcp-servers` | optional | When the Go code is an MCP server's tool contract or transport. |
| `improve-performance` | optional | When a Go slowdown needs a measured before-and-after profile. |
| `design-architecture` | optional | When the work changes package or service boundaries. |
| `test-driven-development` | optional | When the Go change is requested test-first. |
