# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `define-requirements` | optional | When an open product decision changes the breakdown and investigation cannot settle it. |
| `plan-and-implement-changes` | optional | When the plan lacks an ordered change sequence or acceptance criteria to slice from. |
| `investigate-code` | optional | When triage or a spike needs cited code evidence. |
