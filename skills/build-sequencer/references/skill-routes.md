# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `behavior-proof` | required | When an implementation task reaches verification; not for a plan-only request. Or: Before reporting the implementation as working. |
| `scope-grill` | optional | When an unresolved product choice changes the implementation. |
| `temporal-workflows` | optional | When the feature contains durable Temporal workflows. |
| `fleet-ops-router` | optional | When the requested deliverable includes Terraform modules. |
| `rn-expo-builder` | optional | When implementing a React Native/Expo feature. |
| `roadmap-slicer` | optional | When the finished plan should be published as Gitea issues with a roadmap. |
| `red-green-loop` | required | For the explicitly requested test-first implementation flow. |
| `diff-inspector` | required | For the final code review specified by this implementation flow. |
