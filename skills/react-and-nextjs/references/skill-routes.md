# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `build-and-fix-auth` | optional | When a route or server boundary adds login or access checks. |
| `style-web-ui` | optional | When the change is about visual layout, typography or motion. |
| `improve-performance` | optional | When a render or bundle problem needs profiling and measurement. |
| `verify-implementation` | optional | When a UI-visible change needs a real browser check before it is called working. |
