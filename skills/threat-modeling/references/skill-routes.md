# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `secure-web-code` | optional | When a modeled threat needs line-level confirmation in Python, JavaScript/TypeScript or Go web code. |
| `map-codebase` | optional | When repository structure is unknown. |
| `analyze-code-ownership` | optional | When the user also asks who owns the sensitive code the model identifies. |
