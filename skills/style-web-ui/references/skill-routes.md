# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `verify-implementation` | required | Before claiming the edited UI or interaction works. |
| `react-native-expo` | optional | When the target is a React Native/Expo interface rather than a web page. |
| `react-and-nextjs` | optional | When the visual change needs React state or server/client boundary changes. |
| `create-subcult-branding` | optional | When styling a SUBCULT product that needs its brand tokens or visual direction. |
| `throwaway-prototype` | optional | When the visual direction must be chosen by comparing switchable UI variants. |
