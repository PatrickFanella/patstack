# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `temporal-workflows` | optional | When verifying Python Temporal replay, timers or determinism. |
| `browser-workbench` | optional | When the client permits terminal browser QA and no more specific browser contract takes precedence. |
| `repo-atlas` | optional | When repository structure is unknown. |
| `git-surgery` | optional | Only when the user asks to ship changes after the read-only readiness assessment. |
