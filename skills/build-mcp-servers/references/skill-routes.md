# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `verify-implementation` | required | Before claiming the server/tool contract works. |
| `fix-mcp-connections` | optional | When client registration, initialization or tool discovery needs diagnosis. |
| `golang` | optional | When implementing the server in Go. |
| `typescript` | optional | When implementing a TypeScript server contract. |
| `python-projects` | optional | When implementing the server in Python. |
