# Thread init state contract

## Canonical vault surfaces

| Surface | Path |
|---|---|
| Threads root | `001 Projects/Threads/` |
| Threads index | `001 Projects/Threads/Threads Index.md` |
| Thread template | `003 Resources/Templates/Template - Thread.md` |
| Resources and Threads boundary | `003 Resources/Systems/Resources and Threads.md` |

## Standard Thread shape

```
Thread Name/
  Thread Name.md          # home note (Template - Thread)
  Thread Name MOC.md      # map of contents
  Notes/                  # your interpretations, working ideas
  Sources/
    Raw/                  # unprocessed captures
    Research/             # structured source analysis
  Concepts/               # reusable distinctions
  Synthesis/              # claims or models
```

Additional domain folders (`Practice/`, `Case Studies/`, `Reading/`, `Tools/`,
etc.) are welcome when the inquiry needs them. The shape above is the minimum
viable scaffold.

## Sources boundary (from Resources and Threads.md)

- `Sources/Raw/` — unprocessed captures (clippings, PDFs, articles)
- `Sources/Research/` — structured analysis OF sources (claim audits, evidence
  registers, case matrices). Still about the sources.
- `Notes/` — your own ideas, interpretations, working thoughts building on
  everything collected. Your voice, not analysis of someone else's material.
- `Concepts/` — reusable distinctions developed from multiple sources
- `Synthesis/` — claims or models ready to guide future work

## Templater folder mapping

Threads use `Template - Thread` for home notes and MOCs. Notes created in
subdirectories use `Template - Thread Note` (Notes/), `Template - Thread Source`
(Sources/), and `Template - Thread Synthesis` (Synthesis/). Verify the
Templater folder-template mapping after scaffolding.
