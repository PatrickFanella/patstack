# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `edit-fiction` | optional | When the diagnosed problem concerns character motivation or development. Or: When the diagnosed problem concerns dialogue. Or: When a drafted scene fails the established character arc. Or: When a dialogue pass is needed. Or: When a conventional beat needs alternatives. Or: When the draft reaches sentence-level revision. Or: When requested alternatives focus on dialogue. |
| `write-plainly` | required | Before delivering drafted prose; preserve the fiction voice. Or: Before delivering generated prose; preserve the writer's voice. |
| `fictional-worldbuilding` | optional | When new material must be checked against persistent canon. |
| `analyze-and-adapt-stories` | optional | When a writer wants a published work's structure studied or adapted as a model. |
| `build-writing-voice-guide` | optional | When requested prose must match a writer's established style. |
| `design-fictional-languages` | optional | When the diagnosis is flat non-human species or generic language. |
| `write-and-revise-nonfiction` | optional | When a complete draft needs a full manuscript revision pass. |
| `diagnose-branching-stories` | optional | When the story is interactive or branching. |
