# page-copy-forge

Choose the audience, channel and output format first. Use verified product claims and existing voice guidance. Drafting does not authorize sending, scheduling, publishing or changing an account.

Select the matching procedure below and load only that procedure and its needed resources. Each procedure retains its own client, tool and invocation limits. Internal handoffs use the matching procedure below rather than reloading this entrypoint. A reference does not authorize delegation, publication, deployment or an unrelated mutation.

- **page copy forge**: Marketing page copy: write or rewrite homepage, landing, pricing, feature or about-page text, headlines, CTAs and value propositions. Read [the procedure](references/base-workflow.md).
- **social post craft**: Social posts for LinkedIn, X, Instagram, TikTok, Facebook: drafting, threads, calendars, scheduling, engagement, repurposing. Use for 'what should I post' or platform content. Read [the procedure](references/modes/social-post-craft/guide.md).
- **drip sequence planner**: Email sequences: plan or improve a drip, onboarding, nurture, re-engagement or other lifecycle email flow; cold outreach is in its cold-email reference. Read [the procedure](references/modes/drip-sequence-planner/guide.md).
- **content recaster**: Use when adapting an existing article, demo, transcript or report into requested social, newsletter or video drafts. Read [the procedure](references/modes/content-recaster/guide.md).
- **status memo writer**: Internal communications drafts in the organization's formats: status reports, leadership updates, newsletters, FAQs, incident reports, project updates. Read [the procedure](references/modes/status-memo-writer/guide.md).
- **book blurb doctor**: Book marketing copy: diagnose weak blurbs, or write retailer descriptions, taglines and query pitches. Read [the procedure](references/modes/book-blurb-doctor/guide.md).
- **vs page writer**: Comparison pages: write alternative, alternatives, X vs Y or competitor-vs-competitor pages for SEO and sales. Read [the procedure](references/modes/vs-page-writer/guide.md).
