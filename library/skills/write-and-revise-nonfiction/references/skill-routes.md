# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `write-plainly` | required | Before delivering the revised prose. |
| `build-writing-voice-guide` | optional | When matching a supplied writing sample is requested. |
| `verify-claims` | optional | When a draft's factual claims must be checked against cited sources before delivery. |
| `slide-decks` | optional | When spoken content is adapted alongside slides. |
| `investigate-code` | optional | When technical documentation must explain a flow that has not been traced in code. |
| `research-with-sources` | optional | When a gap in the argument requires new cited sources. |
| `edit-fiction` | optional | When manuscript revision reaches character, dialogue or sentence-level fiction problems. |
| `develop-and-draft-fiction` | optional | When revision shows a fiction manuscript's story structure is unresolved. |
