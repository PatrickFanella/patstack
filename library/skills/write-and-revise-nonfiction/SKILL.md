# write-and-revise-nonfiction

Select intake, drafting, revision, technical documentation, summary or spoken adaptation. Preserve sources, user voice and uncertainty. A summary does not authorize invention; technical claims must agree with code. Use write-plainly for the separate prose-quality pass.

Select the matching procedure below and load only that procedure and its needed resources. Each procedure retains its own client, tool and invocation limits. Internal handoffs use the matching procedure below rather than reloading this entrypoint. A reference does not authorize delegation, publication, deployment or an unrelated mutation.

- **article shaping**: Article shaping: turn a markdown file of notes, fragments or a rough draft into a publishable article, paragraph by paragraph, debating openings and format at each step. Read [the procedure](references/base-workflow.md).
- **article beat path**: Article beats: assemble raw material into a narrative one beat at a time, letting the user pick each next pivot. Use when the piece should read as a journey, not an argument. Read [the procedure](references/modes/article-beat-path/guide.md).
- **article restructure**: Article editing: restructure, clarify and tighten an existing article draft section by section. Read [the procedure](references/modes/article-restructure/guide.md).
- **fragment harvest**: Writing fragments: interview the user for claims, vignettes and sharp sentences, appending them to one raw-material document before any structure. Use for fragments or ideation. Read [the procedure](references/modes/fragment-harvest/guide.md).
- **draft reviser**: Revise a drafted manuscript: plan the edit pass, control cascading changes, find problems you no longer see, decide when to stop. Use for fiction or nonfiction after a first draft. Read [the procedure](references/modes/draft-reviser/guide.md).
- **nonfiction gap finder**: Non-fiction gap check: find blind spots and blank spots in a draft before finalizing it, or when feedback feels incomplete. Read [the procedure](references/modes/nonfiction-gap-finder/guide.md).
- **speech shaper**: Adapt written content for listening: compress, front-load value, restructure for podcasts, talks, voice assistants or audio scripts. Use when converting text to spoken form. Read [the procedure](references/modes/speech-shaper/guide.md).
- **tech doc writer**: Use when writing or restructuring technical docs, RFCs or READMEs, translating README variants, or checking docs against code. Read [the procedure](references/modes/tech-doc-writer/guide.md).
- **digest distiller**: Summaries: TL;DR, executive summary, abstract or condensed version of a document, thread or transcript, matched to audience and purpose. Read [the procedure](references/modes/digest-distiller/guide.md).

Read [conditional companions](references/skill-routes.md) only when their stated condition applies.
