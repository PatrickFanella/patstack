# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `verify-claims` | required | Before delivering sourced competitor claims. |
| `research-with-sources` | optional | When finding or refreshing public competitor sources. |
| `write-and-adapt-copy` | optional | When the user also requests comparison-page copy from the researched profiles. |
| `create-sales-materials` | optional | When the user also requests sales battle cards. |
| `plan-content-strategy` | optional | When the research should decide what content to publish. |
| `improve-conversion-rates` | optional | When customer research should be applied to a specific page. |
| `plan-ad-campaigns` | optional | When research findings feed paid ad targeting or messaging. |
