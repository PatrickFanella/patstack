# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `design-fictional-languages` | optional | When a fictional culture needs a consistent phoneme inventory. |
| `fictional-worldbuilding` | optional | When names must reflect a world's institutional or cultural history. |
| `edit-fiction` | optional | When a character name may carry problematic associations. |
