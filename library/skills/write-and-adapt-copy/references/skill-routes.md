# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `build-writing-voice-guide` | optional | When copy must follow or establish a product or personal voice. |
| `verify-claims` | optional | When copy states product, pricing or competitor claims that need source checks. |
| `write-plainly` | optional | When a draft reads as generic AI phrasing and needs the evidence-informed review. |
| `improve-conversion-rates` | optional | When page structure or strategy needs work, not just copy. |
| `diagnose-and-generate-names` | optional | When a tagline needs sound-level work or a new name. |
| `improve-seo` | optional | When comparison pages need schema, metadata or programmatic SEO work. |
| `manage-sales-pipeline` | optional | When the lifecycle stages that trigger an email sequence must be defined. |
| `prepare-product-launch` | optional | When social posts must be coordinated with a launch plan. |
| `create-sales-materials` | optional | When comparison research must also become internal sales collateral. |
| `develop-and-draft-fiction` | optional | When a blurb problem comes from an unclear genre promise or a structural flaw in the book. |
