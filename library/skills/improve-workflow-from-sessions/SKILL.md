# improve-workflow-from-sessions

Separate transcript observations from inferred preferences. Suggestions do not authorize editing memory, global instructions or deployed skills; use the canonical source and current authorization.

Select the matching procedure below and load only that procedure and its needed resources. Each procedure retains its own client, tool and invocation limits. Internal handoffs use the matching procedure below rather than reloading this entrypoint. A reference does not authorize delegation, publication, deployment or an unrelated mutation.

- **find workflow friction**: Reflect on recent sessions to find repeated workflow friction and propose the smallest reusable fix (skill, command, agent, config, playbook). Use for /reflect or learning from past work. Read [the procedure](references/base-workflow.md).
- **chat preference miner**: Preferences from chats: mine recent Codex, Claude Code or OpenCode transcripts for durable working preferences and turn them into skills, rules or workflow docs. Read [the procedure](references/modes/chat-preference-miner/guide.md).
- **mode skill miner**: Use for automate me or create/update my -mode skill: mine this workspace's recent sessions and interview the user to capture their working style as a personal -mode skill. Read [the procedure](references/modes/mode-skill-miner/guide.md).

Load [companion procedures](references/skill-routes.md) only when their stated condition applies.
