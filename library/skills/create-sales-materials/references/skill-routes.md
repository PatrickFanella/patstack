# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `write-and-adapt-copy` | optional | When the request also covers public comparison pages or cold outreach. |
| `slide-decks` | optional | When a pitch deck must be delivered as a presentation file. |
| `research-market-positioning` | optional | When the collateral needs buyer, competitor or positioning evidence the user has not supplied. |
| `model-startup-finances` | optional | When an ROI case or pitch depends on an undecided price or packaging. |
| `manage-sales-pipeline` | optional | When a playbook depends on stage definitions or handoff rules that are not settled. |
