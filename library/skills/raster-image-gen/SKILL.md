# raster-image-gen

Use the current image tool contract and preserve requested transparency and references. Pet atlas validation and activation are conditional; image generation does not authorize uploading or publishing.

Select the matching procedure below and load only that procedure and its needed resources. Each procedure retains its own client, tool and invocation limits. Internal handoffs use the matching procedure below rather than reloading this entrypoint. A reference does not authorize delegation, publication, deployment or an unrelated mutation.

- **raster image gen**: Raster image generation: create or edit bitmap images (photos, sprites, textures, transparent cutouts) with Codex image_gen or the OpenAI CLI fallback. Read [the procedure](references/base-workflow.md).
- **marketing imagery**: Marketing images: create, edit or optimize blog heroes, social graphics, mockups, banners or OG images with AI tools or design apps, including compression. Read [the procedure](references/modes/marketing-imagery/guide.md).
- **pet hatchery**: Use when creating, repairing, upgrading or validating a Codex app animated pet (v2 spritesheet atlas). Generation needs Codex's imagegen skill; validation and packaging run in any client. Read [the procedure](references/modes/pet-hatchery/guide.md).
