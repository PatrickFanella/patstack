# slide-decks

Prefer the installed presentation owner when it covers the task. Preserve editable sources, templates and attribution; render and inspect generated slides before claiming visual quality.

Select the matching procedure below and load only that procedure and its needed resources. Each procedure retains its own client, tool and invocation limits. Internal handoffs use the matching procedure below rather than reloading this entrypoint. A reference does not authorize delegation, publication, deployment or an unrelated mutation.

- **pptx files**: PowerPoint PPTX automation: generate decks from templates or scratch, edit slides, extract content, render thumbnails. Use for programmatic .pptx files; not for deck design advice. Read [the procedure](references/base-workflow.md).
- **slide story design**: Presentation design and critique: structure a talk, design slides, review a deck for clarity and flow. Read [the procedure](references/modes/slide-story-design/guide.md).
