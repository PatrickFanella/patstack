# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `build-writing-voice-guide` | optional | When an approved written voice must guide the editorial plan. |
| `write-and-adapt-copy` | optional | When existing assets need adaptation into the planned channels. |
| `improve-seo` | optional | When the requested roadmap depends on a search-content audit. |
| `research-market-positioning` | optional | When topic choices depend on customer language or competitor content gaps. |
