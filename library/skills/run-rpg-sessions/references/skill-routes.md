# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `fictional-worldbuilding` | optional | When running a persistent setting with recorded canon. Or: When tracking consequential changes across sessions. |
| `develop-and-draft-fiction` | optional | When a campaign's story or scene pacing needs diagnosis between sessions. |
| `edit-fiction` | optional | When an NPC's voice or arc needs dedicated work between sessions. |
