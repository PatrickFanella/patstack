# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `fiction-editor` | optional | When the diagnosed problem concerns character motivation or development. Or: When the diagnosed problem concerns dialogue. Or: When a drafted scene fails the established character arc. Or: When a dialogue pass is needed. Or: When a conventional beat needs alternatives. Or: When the draft reaches sentence-level revision. Or: When requested alternatives focus on dialogue. |
| `prose-unslop` | required | Before delivering drafted prose; preserve the fiction voice. Or: Before delivering generated prose; preserve the writer's voice. |
| `world-bible` | optional | When new material must be checked against persistent canon. |
