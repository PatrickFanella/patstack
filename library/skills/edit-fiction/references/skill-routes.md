# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `build-writing-voice-guide` | optional | When a line edit must preserve or match a captured author voice. |
| `develop-and-draft-fiction` | optional | When the edit exposes a structural problem that must be fixed before polishing. |
| `fictional-worldbuilding` | optional | When a fix must fit world logic or a representation issue is systemic to the world. |
| `write-and-revise-nonfiction` | optional | When notes must become a systematic pass through the whole manuscript. |
