# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `verify-implementation` | required | Before claiming mobile behavior works; honor the current client's device-tool contract. |
| `build-and-fix-auth` | optional | When the feature adds login or access checks. |
| `improve-performance` | optional | When list, animation or startup performance has a measured problem. |
