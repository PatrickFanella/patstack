# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `design-fictional-languages` | optional | When the requested canon work includes constructed-language design. |
| `analyze-technology-impact` | optional | When an invented technology's societal effects must be worked out. |
| `edit-fiction` | optional | When a world problem turns out to be character-focused. |
| `develop-and-draft-fiction` | optional | When a world problem traces to plot structure or story diagnosis. |
| `run-rpg-sessions` | optional | When fate-ledger changes must be applied at a live session boundary. |
