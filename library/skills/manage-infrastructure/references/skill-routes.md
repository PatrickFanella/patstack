# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `verify-implementation` | required | Before claiming validation, plan or Terratest results. |
| `manage-deployment-secrets` | optional | When the module work includes authorized secret delivery or rotation. |
| `build-and-fix-observability` | optional | When a host or service change needs metrics, alerts or dashboards. |
| `bash-scripts` | optional | When the setup-wizard-script mode generates a Bash wizard. |
