# manage-super-productivity

Select planning, maintenance or bridge diagnosis. Use the scoped connector and inspect live capabilities; do not assume tool names or alter unrelated tasks while debugging connectivity.

Select the matching procedure below and load only that procedure and its needed resources. Each procedure retains its own client, tool and invocation limits. Internal handoffs use the matching procedure below rather than reloading this entrypoint. A reference does not authorize delegation, publication, deployment or an unrelated mutation.

- **run an upkeep pass**: Super Productivity upkeep: daily, weekly or monthly cleanup or audit passes that route MCP health, planning and inbox work to the focused skills and end with a report. Read [the procedure](references/base-workflow.md).
- **sp day planner**: Super Productivity planning: recurring daily frameworks, recurrence start times, one-off scheduling, inbox triage, estimates, tags and parent-with-subtask routines. Read [the procedure](references/modes/sp-day-planner/guide.md).
- **sp mcp doctor**: Super Productivity MCP failures: startup, handshake, tool catalog drift, client config or plugin bridge reliability. Read [the procedure](references/modes/sp-mcp-doctor/guide.md).
