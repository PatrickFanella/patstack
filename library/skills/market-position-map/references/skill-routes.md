# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `claim-verifier` | required | Before delivering sourced competitor claims. |
| `primary-source-notes` | optional | When finding or refreshing public competitor sources. |
| `page-copy-forge` | optional | When the user also requests comparison-page copy from the researched profiles. |
| `sales-collateral` | optional | When the user also requests sales battle cards. |
