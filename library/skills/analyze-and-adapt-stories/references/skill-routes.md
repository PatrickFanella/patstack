# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `develop-and-draft-fiction` | optional | When the studied book needs structural interpretation beyond the scene inventory. |
| `plan-and-teach-lessons` | optional | When turning the analysis into a multi-session craft study plan. |
| `edit-fiction` | optional | When extraction leaves a character arc, relationship or lie-want-need gap. |
